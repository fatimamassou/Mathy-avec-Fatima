# Mathy avec Fatima

> **Cours de soutien en mathématiques pour collège et lycée**

**Mathy avec Fatima** est un site web vitrine dédié aux cours de soutien en mathématiques.
Il présente les services proposés, les niveaux accompagnés, la méthode d'enseignement et permet aux parents de contacter directement Fatima.

## 🌐 Présentation

Le site a été conçu pour offrir une expérience simple, claire et accessible aux parents et aux élèves.

L'objectif est de présenter :

* Les différents niveaux scolaires accompagnés
* Les services de soutien proposés
* La méthode pédagogique utilisée
* Des astuces et petits défis de mathématiques
* Les moyens de contact disponibles
* Un formulaire pour envoyer une demande de soutien

## ✨ Fonctionnalités

### 📚 Niveaux

Le site propose un accompagnement pour :

* 1ère année collège
* 2ème année collège
* 3ème année collège
* Tronc Commun
* 1ère année Bac
* 2ème année Bac

Pour les classes de Bac, l'accompagnement peut être adapté à différentes filières :

* Sciences Mathématiques
* Sciences Physiques
* SVT
* Économie / Gestion

### 🎓 Services

Les services présentés comprennent :

* Compréhension des cours
* Accompagnement dans les exercices
* Préparation aux contrôles
* Préparation aux examens
* Remise à niveau et correction des lacunes
* Suivi personnalisé

### 🧠 Méthode pédagogique

La méthode est organisée en quatre étapes :

1. **Comprendre** — Identifier les difficultés de l'élève
2. **Expliquer** — Reprendre la notion avec des explications simples
3. **Pratiquer** — S'entraîner progressivement
4. **Progresser** — Revoir les erreurs et renforcer les points faibles

### 🧮 Espace interactif

Le site contient également un petit espace pédagogique avec :

* Astuces de mathématiques
* Défi du jour
* Question rapide avec réponse interactive

### 📱 Contact

Les visiteurs peuvent contacter Fatima directement via :

* WhatsApp
* Téléphone
* Facebook
* Formulaire de contact

## 🚀 Installation

Aucune installation particulière n'est nécessaire.

### 1. Cloner le projet

```bash
git clone https://github.com/fatimamassou/Mathy-avec-Fatima.git
```

### 2. Accéder au projet

```bash
cd Mathy-avec-Fatima
```

### 3. Ouvrir le site

Ouvrir simplement `index.html` dans un navigateur.

Pour le développement, il est recommandé d'utiliser **VS Code + Live Server**.
